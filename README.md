# CS Amusement Park 项目介绍

## 项目概述

CS Amusement Park 是一个使用 C 语言实现的命令行游乐园管理模拟器。程序使用单向链表管理游乐设施、园内游客和各设施的排队游客，模拟游客进入园区、加入队列、游玩设施、离开园区，以及设施合并与拆分等流程。

## 文件结构

- `main.c`：程序入口，负责欢迎信息、读取游乐园名称和启动命令循环。
- `cs_amusement_park.h`：常量、枚举、结构体与函数声明。
- `cs_amusement_park.c`：游乐园管理逻辑、链表操作、输入处理和输出功能。

## 核心数据结构

- `struct park`：游乐园名称、游客总数、设施链表和自由活动游客链表。
- `struct ride`：设施名称、设施类型、乘坐容量、排队容量、最低身高、排队游客链表和下一设施指针。
- `struct visitor`：游客姓名、身高和下一游客指针。

程序以动态内存配置建立节点，并在游客离开、设施删除或程序结束时释放内存。

## 功能阶段

### Stage 1：初始化和基础管理

- 建立游乐园、设施和游客节点。
- 使用命令循环接收用户输入。
- 新增设施：`a r [ride_name] [ride_type]`。
- 新增游客：`a v [visitor_name] [visitor_height]`。
- 打印游乐园目前状态：`p`。
- 处理基础错误，例如无效设施类型、重复名称、身高范围和园区人数上限。

### Stage 2：设施队列与游客移动

- 在指定位置插入设施：`i [index] [ride_name] [ride_type]`。
- 让游客加入指定设施队列：`j [ride_name] [visitor_name]`。
- 将游客从任意设施队列移回园内：`d [visitor_name]`。
- 将游客转移到另一项设施：`m [visitor_name] [ride_name]`。
- 统计园内游客与排队游客：`t`。
- 统计指定范围设施的排队游客：`c [start_ride] [end_ride]`。

### Stage 3：设施运行与关闭

- 程序结束时释放所有动态内存。
- 让游客永久离开园区：`l [visitor_name]`。
- 运行所有设施，并让每项设施容量以内的游客完成游玩后回到园内：`r`。
- 关闭指定设施：`S [ride_name]`；同类型设施有空位时，优先重新安置原队列游客，否则将其移回园内。

### Stage 4：进阶链表操作

- 合并指定类型中队列最短的两项设施：`M [ride_type]`。
- 拆分一项设施为多个新设施，并尽量平均分配原队列游客：`s [n] [ride_name]`。
- 计划未来执行的命令：`T [n] [command]`。
- 推进模拟时间并执行到期命令：`~ [n]`。

## 技术重点

- 单向链表的插入、删除、遍历和节点重连。
- 多层链表结构：游乐园设施链表，以及每项设施独立的游客队列。
- `malloc` 与 `free` 的动态内存管理。
- 边界条件处理：空链表、头节点、尾节点、队列满、身高不符合条件、同名对象与不存在对象。
- 多文件 C 项目的头文件声明、函数实现和编译链接。

## 编译与运行

```bash
clang -std=c11 -Wall -Wextra cs_amusement_park.c main.c -o cs_amusement_park
./cs_amusement_park
```
